Reproduce this version

Build the committed snapshot or regenerate it from one pinned upstream commit.

The documentation and the examples share one upstream revision: 9f8adb1aabaa8a91180a821111d3f8e668d1c0bf of go-chi/chi. The source module requires Go 1.24; the recorded extraction and examples use Go 1.27.3. Sourcey is pinned to 3.8.3 in the lockfile.

Rebuild the committed documentation

npm ci --ignore-scripts --no-audit --no-fund
npm run build
npm run verify

The committed data/godoc.json was emitted by Sourcey's Go introspector. Snapshot mode builds the same documented declarations without installing Go on the documentation host.

Regenerate from source

node scripts/fetch-upstream.mjs
npm run snapshot
cd examples
go test -v ./...

The fetch step fails if the checkout does not resolve to the pinned commit. The snapshot step invokes Sourcey's godoc command with examples enabled. Timestamps in the snapshot describe extraction time; a new extraction may change that timestamp even when declarations do not change.

What is verified

The site check inventories generated HTML, tests internal file and fragment targets, checks that the expected exported symbols appear in the reference, and verifies that source-map links use the pinned commit. The Go tests exercise observable HTTP behavior in the three recipes. Coverage lists the extracted surface and its limits.

The public source repository keeps configuration, original recipes, tests, the raw Go snapshot, the upstream license and reproducible scripts. The published site is static HTML generated by Sourcey.
