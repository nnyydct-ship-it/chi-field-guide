# Chi Field Guide: source, behavior and renderer gaps

- **Useful surface:** the public site combines chi's generated root and middleware reference with original recipes for path/method handling, middleware nesting and cooperative deadlines. It is an independent documentation project, with visible upstream links, source attribution and no claim of maintainer endorsement. The maintained MIT upstream is pinned at `9f8adb1aabaa8a91180a821111d3f8e668d1c0bf`, committed 18 October 2026.
- **Actual extraction:** Sourcey 3.8.3's native `godoc` adapter read the real Go module, rather than a handwritten API stub. The committed snapshot contains 57 functions, 20 types and 45 methods, plus seven constants/variables: 129 source-mapped declarations across two packages. Interface members and struct fields are rendered within types and not counted again.
- **Checked examples:** Go 1.27.3 runs six test functions, including four path/method table cases. The HEAD test uses a real local HTTP server so body suppression is exercised. The timeout test observes cancellation and 504 without claiming that middleware kills an uncooperative handler.
- **Governed validation:** `runx-cli 0.10.2` executed the source-reviewed site verifier. It returned exit 0 for 14 HTML pages, 485 local targets, 198 fragments and all 129 API anchors. The five-receipt tree verifies under Runx's native configured-trust verifier using the exported public key. These are local Ed25519 receipts, not external notarization or upstream approval.
- **Concrete renderer defect:** a direct `sourcey build` with flat URLs emits `go-api.html`, while generated godoc links target missing `go-api/index.html`. `node scripts/repro-godoc-navigation.mjs` reproduces it on the committed input. The published build copies the identical Sourcey overview to that compatibility path, then verifies every local link. This workaround is declared in the source.
- **Maintainer-facing gap:** godoc source links take the site's global repository/ref. An independent mixed guide needs its own prose repository and a different pinned upstream reference. A per-adapter repository/ref would avoid misdirected edit links. This site leaves those global edit links disabled and publishes an exhaustive pinned source map instead.
- **Publication and limits:** public read-backs of four representative pages match the built bytes. Existing Chrome showed readable homepage/API layouts and navigation. The domain is an existing operator GitHub Pages domain; its root hosts another project. Whether that satisfies a separate host-credibility rule needs the posting owner's judgment. The library maintainers have not adopted this guide; no mobile visual check is claimed.

Rebuild the site with `npm ci --ignore-scripts --no-audit --no-fund`, `npm run build`, and `npm run verify`. Verify the public receipt bundle with `node scripts/verify-receipts.mjs`. Regenerate the source snapshot and run the Go tests using the documented pinned checkout. All build and verification paths need no account or paid API call.
